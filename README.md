## 🛠️ Troubleshooting Tips  

- **No models appear after scanning?** Make sure you selected the correct folders. Also check that your files have common extensions like `.safetensors` or `.gguf`. If you have custom extensions, tensorvillage can still index them through the *Add Extension* option in settings.  
- **Can’t find the virtual drive?** Look for a new drive letter (like `T:`) in “This PC.” If it is not visible, restart tensorvillage as administrator (right-click → Run as administrator).  
- **Duplicate detection is slow?** For very large libraries, the first scan may take a few minutes. Subsequent scans are instantaneous because the index is cached.  
- **Files are read-only?** tensorvillage never modifies original files unless you explicitly delete, rename, or move them. It always asks for confirmation first.  
- **Need to uninstall?** Go to Windows Settings → Apps → tensorvillage → Uninstall. Your model files are untouched.
